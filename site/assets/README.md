# Token Assets

## Logo Files

The following logo files are placeholders and should be replaced with the actual $CLA token logo:

- `logo.png` - Main token logo (recommended: 512x512px or larger)
- `logo-512.png` - 512x512 variant for various uses
- `logo-256.png` - 256x256 variant for favicons and smaller displays

The actual logo image was provided in the project setup. Please ensure all three files are present before deploying to production.

## Adding the Logo

1. Save the $CLA token logo as `logo.png` in this directory
2. Create 512x512 and 256x256 variants (can be copies if resizing isn't available)
3. Optionally, generate a favicon.ico from the logo

The logo should be a professional representation of the Quaxis Clarus brand.
